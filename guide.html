Guide EcoCoco

Modifier, enregistrer et publier le site EcoCoco

Ce guide explique quoi modifier, quel dossier envoyer en ligne, comment garder des sauvegardes et comment publier le site sur GitHub Pages.

Dossiers Module de gestion Images Sauvegardes Upload GitHub Erreurs courantes
La regle la plus importante Pour publier le site, envoyer uniquement le contenu du dossier 1-Site_a_uploader. Ne pas envoyer les dossiers 2-Gestion_admin et 3-Travail_ne_pas_uploader.
1-Site_a_uploader Dossier public du site. C'est celui qui part sur GitHub ou chez l'hebergeur.
2-Gestion_admin Module local pour modifier le site. Il reste sur l'ordinateur.
3-Travail_ne_pas_uploader Documents de travail, photos originales, captures, guides et sauvegardes.

1. Utiliser le module de gestion

Le module sert a modifier le contenu sans toucher au code.

  1. Ouvrir le dossier 2-Gestion_admin.
  2. Double-cliquer sur Lancer_Admin_EcoCoco.bat.
  3. Le navigateur ouvre la page de gestion locale.
  4. Choisir un onglet : Modifier les textes, Style du site, Images & logos ou Finaliser.
  5. Faire les modifications.
  6. Cliquer sur Enregistrer.
  7. Verifier l'apercu a droite.
  8. Quand tout est bon, aller dans Finaliser puis cliquer sur Preparer le dossier a uploader.

2. Modifier les textes

Tous les textes importants du site sont ranges par section.

  1. Aller dans Modifier les textes.
  2. Utiliser la recherche pour trouver rapidement un bloc.
  3. Exemples de recherche : promoteur, contact, impact, Carte impact, financement.
  4. Modifier le champ voulu.
  5. Cliquer sur Enregistrer.

Astuce : pour modifier les quatre chiffres dans le bloc d'impact, rechercher Carte impact.

3. Modifier le style du site

Cette partie sert a changer l'apparence generale.

  • Couleurs principales : couleurs du texte, du fond, du vert EcoCoco, du brun coco, etc.
  • Polices : police du texte, police des titres, taille generale.
  • En-tete, menu et logo : hauteur de la barre menu, opacite derriere les menus, taille du rond du logo, taille du logo dans le rond.
  • Banniere d'accueil : hauteur de la grande banniere et position du texte.
  • Mise en page : espacements et arrondis.

Apres modification, cliquer sur Enregistrer puis verifier l'apercu.

4. Modifier ou ajouter des images

Les images importantes peuvent etre remplacees directement depuis le module.

  1. Aller dans Images & logos.
  2. Trouver l'image a remplacer : logo, banniere, photo de section, promoteur, etc.
  3. Choisir une image deja presente dans la liste, ou cliquer sur Envoyer une nouvelle image.
  4. Choisir l'image sur l'ordinateur.
  5. Cliquer sur Enregistrer.

Les nouvelles images sont rangees ici :

1-Site_a_uploader/assets/img/uploads/

Conseil : utiliser des images JPG, PNG ou WEBP. Eviter les images trop lourdes pour que le site charge rapidement.

5. Enregistrer et garder des sauvegardes

Il y a deux niveaux de sauvegarde : automatique et manuelle.

Sauvegarde normale

  1. Apres chaque modification importante, cliquer sur Enregistrer.
  2. Le site public local est mis a jour dans 1-Site_a_uploader.
  3. Une copie de securite est creee automatiquement dans le dossier de travail.

Les copies automatiques sont ici :

3-Travail_ne_pas_uploader/sauvegardes-admin/

Copie de securite manuelle

  1. Aller dans Finaliser.
  2. Cliquer sur Telecharger une copie.
  3. Conserver ce fichier dans un endroit sur.

Restaurer une ancienne copie

  1. Aller dans Finaliser.
  2. Cliquer sur Restaurer une copie.
  3. Choisir le fichier de sauvegarde.
  4. Cliquer sur Enregistrer.
  5. Verifier l'apercu.

6. Preparer le dossier a uploader

Cette etape finalise le site avant publication.

  1. Ouvrir le module de gestion.
  2. Cliquer sur Enregistrer.
  3. Aller dans Finaliser.
  4. Cliquer sur Preparer le dossier a uploader.
  5. Utiliser ensuite le dossier 1-Site_a_uploader pour la publication.
A envoyer
  • index.html
  • styles.css
  • script.js
  • site-config.js
  • assets
Ne pas envoyer
  • 2-Gestion_admin
  • 3-Travail_ne_pas_uploader
  • Les captures d'erreurs
  • Les documents Word/PDF de travail
  • Les archives .rar seules

7. Publier sur GitHub Pages

Methode simple depuis le navigateur, sans ligne de commande.

Premiere publication

  1. Aller sur github.com et se connecter.
  2. Cliquer sur New repository.
  3. Donner un nom au depot, par exemple ecococo-site.
  4. Choisir Public si le site doit etre publie gratuitement avec GitHub Pages.
  5. Creer le depot.
  6. Cliquer sur Add file puis Upload files.
  7. Ouvrir sur l'ordinateur le dossier :
F:\Documents\Programmation\EcoCoco\1-Site_a_uploader
  1. Glisser dans GitHub le contenu du dossier, pas le dossier parent lui-meme.
  2. Verifier que index.html est bien a la racine du depot GitHub.
  3. Cliquer sur Commit changes.
  4. Aller dans Settings puis Pages.
  5. Dans Build and deployment, choisir Deploy from a branch.
  6. Choisir la branche main et le dossier / root.
  7. Cliquer sur Save.
  8. Attendre quelques minutes, puis ouvrir le lien GitHub Pages indique par GitHub.

Mettre a jour le site deja publie

  1. Modifier le site dans le module de gestion.
  2. Cliquer sur Enregistrer.
  3. Cliquer sur Preparer le dossier a uploader.
  4. Retourner dans le depot GitHub du site.
  5. Cliquer sur Add file puis Upload files.
  6. Glisser les fichiers et le dossier assets depuis 1-Site_a_uploader.
  7. GitHub remplace les anciens fichiers par les nouveaux.
  8. Cliquer sur Commit changes.
  9. Attendre quelques minutes et rafraichir le site public.

Si les changements ne sont pas visibles tout de suite, attendre encore quelques minutes puis faire Ctrl + F5 dans le navigateur.

8. Publier chez un autre hebergeur

La logique est la meme que pour GitHub.

  1. Preparer le dossier a uploader depuis l'admin.
  2. Envoyer le contenu de 1-Site_a_uploader dans le dossier public de l'hebergeur.
  3. Le fichier index.html doit etre a la racine du site public.
  4. Verifier que le dossier assets est bien envoye avec toutes les images.

9. Erreurs courantes et solutions

Quelques problemes classiques et leur correction.

Le site affiche une ancienne version

  • Verifier que vous avez clique sur Enregistrer.
  • Verifier que vous avez clique sur Preparer le dossier a uploader.
  • Sur le site public, faire Ctrl + F5.
  • Sur GitHub Pages, attendre quelques minutes apres le commit.

Une image ne s'affiche pas

  • Verifier que le dossier assets a bien ete envoye.
  • Verifier que l'image est bien dans assets/img ou assets/img/uploads.
  • Eviter les noms de fichiers trop compliques si l'image est ajoutee manuellement.

Le module de gestion ne s'ouvre pas

  • Utiliser Lancer_Admin_EcoCoco.bat, pas un double-clic direct sur admin.html.
  • Si une fenetre noire s'ouvre, la laisser ouverte pendant l'utilisation du module.
  • Fermer cette fenetre seulement quand vous avez fini.

J'ai fait une mauvaise modification

  • Ne pas publier tout de suite.
  • Aller dans Finaliser puis utiliser Restaurer une copie.
  • Si besoin, utiliser une copie automatique dans 3-Travail_ne_pas_uploader/sauvegardes-admin.

10. Checklist avant publication

A faire avant chaque upload.

  • Les textes importants ont ete verifies.
  • Les images s'affichent correctement.
  • Le logo et le menu sont lisibles.
  • Le formulaire de contact ouvre bien un email vers EcoCoco.
  • Le site a ete enregistre.
  • Le dossier a uploader a ete prepare.
  • Seul le contenu de 1-Site_a_uploader est envoye.
Resume rapide : Modifier dans le module, cliquer sur Enregistrer, aller dans Finaliser, preparer le dossier a uploader, puis envoyer uniquement le contenu de 1-Site_a_uploader.
